# Amazon Migration Hub (amazon-migration-hub)
AWS Migration Hub provides a single location to track the progress of application migrations across multiple AWS and partner solutions. It allows you to choose the migration tools that best fit your needs and get a single view of the status of all migrations.

## APIs

### AWS Migration Hub API
The AWS Migration Hub API provides programmatic access to create and manage migration tasks, progress updates, discovered resources, and migration status tracking across your application migration projects.
