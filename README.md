## Features

| Name | Description |
|------|-------------|
| Centralized Migration Tracking | Track migration progress across multiple applications and migration tools from a single console. |
| Multi-Tool Integration | Integrate with AWS Database Migration Service, Server Migration Service, and partner tools. |
| Application Discovery | Discover on-premises servers and dependencies to plan migrations effectively. |
| Migration Status Notifications | Receive real-time updates on task progress and resource migration status. |
| Resource Association | Associate discovered resources with migration tasks for tracking. |

## Use Cases

| Name | Description |
|------|-------------|
| Large-Scale Cloud Migration | Manage complex migrations of hundreds or thousands of servers to AWS. |
| Migration Portfolio Management | Track the status of all applications in a migration portfolio. |
| Multi-Tool Orchestration | Coordinate migrations using multiple AWS and partner migration tools simultaneously. |
| Migration Reporting | Generate progress reports and status updates for stakeholders. |

## Integrations

| Name | Description |
|------|-------------|
| AWS Server Migration Service | Track SMS migration job progress in Migration Hub. |
| AWS Database Migration Service | Monitor DMS database migration tasks from Migration Hub. |
| AWS Application Discovery Service | Import discovery data to identify and plan server migrations. |
| AWS CloudFormation | Track CloudFormation stack deployments as migration tasks. |
